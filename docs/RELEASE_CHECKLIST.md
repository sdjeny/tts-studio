## 快速发布流程

```bash
# 1. 停止当前服务
taskkill /F /IM python.exe

# 2. 运行测试
python tests/run_ui_tests.py

# 3. 如果测试通过，启动服务
python -m app.main

# 4. 手动检查关键功能
# 访问 http://localhost:7860

# 5. 确认无误后发布
```

---

## 回滚方案

如果新版本有问题，可以快速回滚：

```bash
# 1. 停止服务
taskkill /F /IM python.exe

# 2. 恢复上一个版本
git checkout HEAD~1 -- app/ui.py

# 3. 重新启动
python -m app.main
```
