# 多音字编辑器使用说明与最佳实践

> **重要提示**：由于 Gradio 框架的技术限制，文本编辑器功能有一定的局限性。本文档详细说明当前能力和最优工作流程。

---

## ⚠️ Gradio 框架的技术限制

### 无法实现的功能

1. **❌ 无法自动获取光标位置**
   - Gradio Textbox 组件不提供光标位置 API
   - 无法知道用户在文本的哪个位置

2. **❌ 无法自动获取选中的文本**
   - Gradio 没有文本选择事件监听
   - 无法知道用户用鼠标选中了哪些字

3. **❌ 无法高亮显示特定字符**
   - Gradio Textbox 是纯文本组件
   - 不支持富文本或语法高亮

### 可以实现的功能

1. **✅ 显示和编辑文本**
   - 可以显示带标记的文本
   - 用户可以手动编辑文本

2. **✅ 在指定位置插入标记**
   - 可以在文本开头/末尾添加标记
   - 可以替换指定的第 N 个出现的字符
   - 可以包裹整个文本

3. **✅ 智能替换**
   - 可以替换第一个、第二个、第三个...出现的字符
   - 支持精确控制替换位置

## 🎯 当前实现的工作流程

### 多音字标注流程

**核心功能**：可以精确替换第 N 个出现的字符

#### 示例：标注"银行行长"中的不同"行"字

**场景 1：标注第 1 个"行"（银行的行，读 háng）**

1. **查看文本**：
   ```
   银行行长
   ```

2. **设置参数**：
   - 待标注字：`行`
   - 替换为：`航`
   - 第几个：`1` （替换第 1 个出现的"行"）

3. **点击按钮**："➕ 标注指定的字"

4. **结果**：
   ```
   银[phoneme=航]行[/phoneme]行长
   ```

---

**场景 2：标注第 2 个"行"（行长的行，读 xíng）**

1. **查看文本**：
   ```
   银行行长
   ```

2. **设置参数**：
   - 待标注字：`行`
   - 替换为：`邢` （同音字，读 xíng）
   - 第几个：`2` （替换第 2 个出现的"行"）

3. **点击按钮**："➕ 标注指定的字"

4. **结果**：
   ```
   银行[phoneme=邢]行[/phoneme]长
   ```

---

**场景 3：同时标注两个"行"字**

1. **第 1 步**：标注第 1 个"行"
   - 待标注字：`行`
   - 替换为：`航`
   - 第几个：`1`
   - 结果：`银[phoneme=航]行[/phoneme]行长`

2. **第 2 步**：标注第 2 个"行"（注意：现在是第 2 个未标记的"行"）
   - 待标注字：`行`
   - 替换为：`邢`
   - 第几个：`2`
   - 结果：`银[phoneme=航]行[/phoneme][phoneme=邢]行[/phoneme]长`

**注意**：每次标注后，文本中会增加标记，所以"第几个"是指**未标记的原始字符**的位置。

## 💡 最佳实践技巧

### 技巧 1：逐个标注多音字

**推荐做法**：
```
原文本：银行行长有着长长的尾巴

第1步：标注第1个"行" → 银[phoneme=航]行[/phoneme]行长...
第2步：标注"长"（zhǎng）→ ...[phoneme=掌]长[/phoneme]...
第3步：标注第2个"长"（cháng）→ ...[phoneme=常]长[/phoneme]...
```

**不推荐做法**：
```
❌ 一次性输入多个字的标注
❌ 期望系统自动识别所有多音字
```

### 技巧 2：利用手动编辑

如果快捷操作不够灵活，可以直接在文本框中手动编辑：

**示例**：
```
原始文本：银行行长

手动编辑为：银[phoneme=航]行[/phoneme][phoneme=掌]长[/phoneme]
```

**优势**：
- ✅ 完全控制标记位置
- ✅ 可以一次性标注多个字
- ✅ 可以调整标记顺序

### 技巧 3：先标注多音字，再调整语气

**推荐顺序**：
1. 先标注所有多音字
2. 再添加停顿标记
3. 最后调整语速和音调

**原因**：
- 多音字是基础，影响读音
- 语气变化是在正确读音基础上的修饰
- 避免混乱

### 技巧 4：频繁试听验证

每标注 2-3 个字后，点击"🔊 试听当前效果"按钮，确认读音正确。

**不要**等到所有标注完成后才试听，这样发现问题时难以定位。

## 🔧 各种操作的具体说明

### 1. 多音字标注

**功能**：将指定的字替换为同音字，让 TTS 按照同音字的读音来读

**操作**：
1. 在"待标注字"输入要标注的字（如：行）
2. 在"替换为"输入同音字（如：航）
3. 点击"➕ 标注选中的字"

**结果**：
```
原文本：银行
结果：银[phoneme=航]行[/phoneme]
读音：yín háng（正确）
```

**注意事项**：
- ⚠️ 只替换第一个出现的字符
- ⚠️ 如果需要标注多个相同的字，需要多次操作
- ⚠️ 替换字必须是单个汉字

---

### 2. 插入停顿

**功能**：在文本的指定位置添加停顿

**操作模式**：
1. **在末尾插入**（默认）
   - 调整"停顿时长（毫秒）"滑块
   - 选择"在末尾插入"
   - 点击"⏸️ 插入停顿"
   - 结果：`你好世界[pause=300]`

2. **在开头插入**
   - 调整"停顿时长（毫秒）"滑块
   - 选择"在开头插入"
   - 点击"⏸️ 插入停顿"
   - 结果：`[pause=300]你好世界`

3. **替换选中文本（需手动输入）**
   - 由于 Gradio 限制，无法自动获取选中的文本
   - 选择此模式后，系统会提示手动编辑
   - 用户需要在文本框中手动将选中的文字替换为 `[pause=Xms]`

**建议时长**：
- 短停顿：100-200ms（逗号级别）
- 中停顿：300-500ms（句号级别）
- 长停顿：600-1000ms（段落间隔）
- 超长停顿：1000-2000ms（戏剧性停顿）

**注意事项**：
- ⚠️ "在末尾/开头插入"只能在整个文本的开头或末尾添加
- ⚠️ 如果需要在中间插入停顿，有两种方法：
  
  **方法 1：手动编辑**
  ```
  原文本：你好世界
  
  手动编辑为：你好[pause=200]世界
  ```
  
  **方法 2：分步处理**
  - 先将文本分成两部分
  - 分别生成音频
  - 在拼接时添加停顿

---

### 3. 添加强调

**功能**：用强调标记包裹整个文本

**操作**：
1. 选择强调程度（强烈/中等/减弱）
2. 点击"❗ 包裹整个文本"

**结果**：
```
原文本：非常重要
操作：强烈强调
结果：[emphasis=strong]非常重要[/emphasis]
```

**强调程度说明**：
- **强烈强调**：语速 -20%，音调 +10Hz（放慢+提高音调）
- **中等强调**：语速 -10%（稍慢）
- **减弱强调**：无效果

**注意事项**：
- ⚠️ 会包裹**整个文本**，不能只强调部分文字
- ⚠️ 如果需要强调部分文字，需要手动编辑

**手动强调部分文字的方法**：
```
原文本：这非常重要

手动编辑为：这[emphasis=strong]非常[/emphasis]重要
```

---

### 4. 整体语气调整

**功能**：用 rate 和 pitch 标记包裹整个文本

**操作**：
1. 调整"语速调整（百分比）"滑块
2. 调整"音调调整（赫兹）"滑块
3. 点击"✅ 应用语气设置到全文"

**结果**：
```
原文本：突然！他发现了秘密
操作：语速 +30%，音调 +20Hz
结果：[rate=+30%][pitch=+20Hz]突然！他发现了秘密[/pitch][/rate]
```

**常用场景**：
- **惊讶/兴奋**：语速 +20~30%，音调 +15~20Hz
- **沉思/悲伤**：语速 -20~30%，音调 -10~15Hz
- **紧张/急促**：语速 +30~50%，音调 +10~15Hz
- **神秘/低沉**：语速 -30~40%，音调 -15~20Hz

**注意事项**：
- ⚠️ 会应用到**整个文本**
- ⚠️ 如果文本已有 rate/pitch 标记，会先移除旧的，再添加新的

---

### 5. 清除所有标记

**功能**：移除所有方括号标记，恢复纯文本

**操作**：
点击"🧹 清除所有标记"按钮

**结果**：
```
原文本：银[phoneme=航]行[/phoneme][pause=300]
结果：银行
```

**注意事项**：
- ⚠️ 此操作不可撤销
- ⚠️ 清除前请确认不需要这些标记

## 📝 完整示例

### 示例：标注"银行行长"

**目标**：让 TTS 正确读出"银行行长"（yín háng háng zhǎng）

**步骤**：

1. **初始文本**：
   ```
   银行行长
   ```

2. **标注第1个"行"（háng）**：
   - 待标注字：行
   - 替换为：航
   - 点击"标注选中的字"
   - 结果：`银[phoneme=航]行[/phoneme]行长`

3. **标注"长"（zhǎng）**：
   - 待标注字：长
   - 替换为：掌
   - 点击"标注选中的字"
   - 结果：`银[phoneme=航]行[/phoneme][phoneme=掌]长[/phoneme]`

4. **试听验证**：
   - 点击"🔊 试听当前效果"
   - 确认读音正确

5. **完成**：
   - 最终文本：`银[phoneme=航]行[/phoneme][phoneme=掌]长[/phoneme]`
   - TTS 读音：yín háng háng zhǎng ✅

## ❓ 常见问题

### Q1: 为什么不能自动获取我选中的字？

**A**: 这是 Gradio 框架的技术限制。Gradio Textbox 组件不提供文本选择事件的监听接口。我们已经在 GitHub 上提交了 feature request，希望未来的版本能支持。

**临时方案**：手动输入待标注字。

---

### Q2: 我想标注第2个"行"字，怎么办？

**A**: 当前实现只替换第一个出现的字符。如果需要标注第2个"行"字，有两种方法：

**方法 1：分步操作**
```
第1步：先标注第1个"行" → 银[phoneme=航]行[/phoneme]行长
第2步：再次标注"行" → 银[phoneme=航]行[/phoneme][phoneme=航]行[/phoneme]长
```

**方法 2：手动编辑**
直接在文本框中手动输入标记：
```
银[phoneme=航]行[/phoneme][phoneme=航]行[/phoneme]长
```

---

### Q3: 我想在文本中间插入停顿，怎么办？

**A**: 当前"插入停顿"功能只能在末尾添加。如果需要在中间插入，需要手动编辑：

**示例**：
```
原文本：你好世界

手动编辑为：你好[pause=200]世界
```

---

### Q4: 标记太多，看起来很乱，怎么办？

**A**: 建议使用以下方法：

1. **分段处理**：不要一次性标注整段文本，分成小段处理
2. **频繁试听**：每标注几个字就试听一次，确保正确
3. **使用清除功能**：如果标错了，可以清除重新开始

---

### Q5: 能否支持批量标注？

**A**: 当前不支持批量标注。每个多音字需要单独标注。

**原因**：
- 不同的多音字可能需要不同的替换字
- 批量标注容易出错
- 逐个标注更可控

**建议**：耐心逐个标注，确保每个字都正确。
