# 多音字与语气标记编辑器 - 使用指南

## 📋 功能概述

为每个对白片段提供可视化的多音字标注和语气调整功能，操作人员无需记忆复杂的标记语法。

## 🎯 核心功能

### 1. 原始文本显示与编辑

- **位置**：选中表格中的某一行后，在"多音字与语气标记编辑"区域显示
- **功能**：
  - 显示当前对白的完整文本（包含所有标记）
  - 可以直接手动编辑标记
  - 实时反映修改

### 2. 多音字标注

#### 使用方法
1. 在"多音字"输入框中输入需要标注的字（例如：行）
2. 在"替换为"输入框中输入同音字（例如：航）
3. 点击"➕ 标注多音字"按钮

#### 效果
```
原文本：银行行长
操作：多音字=行，替换为=航
结果：银[phoneme=航]行[/phoneme][phoneme=航]行[/phoneme]长
```

#### 注意事项
- 每次只替换第一个出现的字符
- 多音字和替换字都必须是单个汉字
- 如果原文本中不包含该字，会提示错误

### 3. 停顿插入

#### 使用方法
1. 调整"停顿时长(ms)"滑块（100ms - 2000ms）
2. 点击"⏸️ 插入停顿"按钮

#### 效果
```
原文本：你好世界
操作：插入 300ms 停顿
结果：你好世界[pause=300]
```

#### 建议时长
- 短停顿：100-200ms（逗号级别）
- 中停顿：300-500ms（句号级别）
- 长停顿：600-1000ms（段落间隔）
- 超长停顿：1000-2000ms（戏剧性停顿）

### 4. 强调标记

#### 使用方法
1. 选择强调程度：
   - `strong` - 强烈强调
   - `moderate` - 中等强调
   - `reduced` - 减弱强调
2. 点击"❗ 添加强调"按钮

#### 效果
```
原文本：非常重要
操作：strong 强调
结果：[emphasis=strong]非常重要[/emphasis]
```

### 5. 语速和音调调整

#### 使用方法
1. 调整"语速调整 (%)"滑块：
   - 负数 = 慢速（-50% 到 -5%）
   - 正数 = 快速（+5% 到 +50%）
   - 0 = 正常语速

2. 调整"音调调整 (Hz)"滑块：
   - 负数 = 低音（-20Hz 到 -5Hz）
   - 正数 = 高音（+5Hz 到 +20Hz）
   - 0 = 正常音调

3. 点击"✅ 应用语气设置到选中文本"按钮

#### 效果
```
原文本：突然！他发现了秘密
操作：语速 +30%，音调 +20Hz
结果：[rate=+30%][pitch=+20Hz]突然！他发现了秘密[/pitch][/rate]
```

#### 常用场景
- **惊讶/兴奋**：语速 +20~30%，音调 +15~20Hz
- **沉思/悲伤**：语速 -20~30%，音调 -10~15Hz
- **紧张/急促**：语速 +30~50%，音调 +10~15Hz
- **神秘/低沉**：语速 -30~40%，音调 -15~20Hz

### 6. 清除所有标记

#### 使用方法
点击"🧹 清除所有标记"按钮

#### 效果
移除文本中所有的方括号标记，恢复纯文本

### 7. 试听效果

#### 使用方法
点击"🔊 试听当前标记效果"按钮

#### 功能
- 立即生成带标记的音频
- 在下方播放器中播放
- 可以快速验证标记效果

## 💡 最佳实践

### 多音字标注技巧

1. **常见多音字对照表**：
   ```
   行：hang2→航（银行），xing2→形（行动）
   长：chang2→常（长短），zhang3→掌（生长）
   重：zhong4→仲（重要），chong2→虫（重复）
   乐：le5→勒（快乐），yue4→月（音乐）
   好：hao3→郝（好坏），hao4→号（爱好）
   着：zhe5→这（看着），zhao2→找（着急）
   ```

2. **批量标注**：
   - 先标注所有多音字
   - 再调整语气
   - 最后试听确认

### 语气变化设计

1. **一波三折示例**：
   ```
   [rate=-30%]那航掌[/rate]        # 慢速强调
   [pause=300]                      # 悬念停顿
   [pitch=+15Hz]竟然仲新[/pitch]    # 高音惊讶
   [rate=+20%]走进了那家月器店[/rate]  # 快速叙述
   [pitch=-10Hz]看着那些郝玩的乐器[/pitch]  # 低音沉思
   [rate=-10%]他这迷了[/rate]       # 慢速着迷
   [pause=400]                      # 高潮前停顿
   [pitch=+20Hz]突然！[/pitch]      # 高音惊叹
   [rate=+30%]他发现了一个常虫的箱子[/rate]  # 快速兴奋
   [pause=500]                      # 最大悬念
   [rate=-40%][pitch=-15Hz]里面...到底是什么呢？[/pitch][/rate]  # 神秘结尾
   ```

2. **情感曲线**：
   - 开头：慢速引入
   - 发展：逐渐加快
   - 高潮：快速+高音
   - 结尾：慢速+低音（或反之）

### 停顿使用原则

1. **自然停顿**：
   - 逗号处：100-200ms
   - 句号处：200-300ms
   - 段落间：400-600ms

2. **戏剧性停顿**：
   - 悬念前：300-500ms
   - 转折处：400-600ms
   - 高潮前：500-800ms

## ⚠️ 注意事项

1. **标记顺序**：
   - 建议顺序：多音字 → 停顿 → 强调 → 语速/音调
   - 嵌套时注意闭合标签的顺序

2. **避免过度标记**：
   - 只对关键的多音字标注
   - 语气变化要有层次感
   - 停顿不宜过多

3. **试听验证**：
   - 每次修改后都要试听
   - 确保效果符合预期
   - 必要时调整参数

4. **保存工程**：
   - 标记会保存在工程中
   - 定期保存避免丢失
   - 可以导出为 JSON 备份

## 🔧 技术实现

### 标记语法

```
[phoneme=同音字]原字[/phoneme]  - 多音字替换
[rate=X%]文本[/rate]            - 语速控制
[pitch=XHz]文本[/pitch]         - 音调控制
[pause=Xms]                     - 停顿（无结束标签）
[emphasis=level]文本[/emphasis] - 强调
```

### 处理流程

1. **用户操作** → UI 收集参数
2. **生成标记** → 拼接标记字符串
3. **更新显示** → 刷新文本框
4. **试听验证** → 调用 TTS 引擎
5. **保存工程** → 持久化存储
